# NAILBUS

Site web e-commerce pour une entreprise de services de manucure, développée avec Symfony 6.4.20 et MySQL.

## Fonctionnalités

- **Utilisateur non connecté —** Lecture & recherche du catalogue de produits et de prestations, du calendrier des rendez-vous et des avis clients ; ajouter des produits au panier ; inscription / connexion.
- **Utilisateur connecté —** gestion du compte ; passage de commande & paiement Stripe avec envoi de facture par mail ; prendre un rendez-vous pour une prestation à une plage horaire du calendrier ; rédiger et envoyer un avis client.

## Stack technique

- PHP 8.5+
- Symfony 6.4.20
- MySQL
- Doctrine ORM
- KnpPaginatorBundle
- FullCalendar 6
- Twig

## Prérequis

- PHP 8.5 ou supérieur
- MySQL
- Composer
- Symfony CLI
